# xphoto 相册

> 一个电脑和手机通用的相册：电脑上是桌面应用，手机上是原生 Android 相册；同一 Wi-Fi 下扫码就能把电脑相册带到手机，不在同一网络时用 Tailscale 加密连接。

xphoto 参考 Microsoft Photos 与小米相册的排版：电脑端按日期时间线展示、左侧文件夹导航；手机端保留本地相册、文件夹分类、日期分组、右侧快速滚动和双指缩放。它不是网盘套壳，也不是网页快捷方式：电脑端直接读取本机文件夹，手机端直接读取手机相册，只有跨设备时才通过局域网/Tailscale 传输。

## 功能

### 电脑端（Windows 便携版）

- 左侧添加任意本地文件夹，按文件夹自动生成相簿
- 按日期分组的时间线，支持网格密度、Ctrl + 滚轮缩放
- 收藏、最近、回收站
- 图片与视频查看，视频支持播放
- 手机扫码连接（局域网二维码 + 访问口令）
- Tailscale 远程访问 + 独立访问密码
- 123 云盘、WebDAV（坚果云 / Nextcloud / AList / 群晖等）
- 长按/框选多选：下载、移动、收藏、删除、分享、查看位置
- 每个日期可一键“全选”
- 缩略图缓存查看与清理
- 完整更新公告（从 1.0 到当前版本）

### 手机端（Android）

- 打开即进入手机本机相册，不强制连接电脑
- 保留文件夹分类、日期分组、右侧快速滚动、双指缩放
- 手机本机图片/视频可多选：收藏、删除、分享
- 自己的手机回收站：清空后才真正删除手机文件
- 连接电脑后可看电脑相册，可把电脑图片删到电脑回收站
- 电脑图片先下载到手机缓存再分享给微信/QQ，不再只显示 image 占位
- 全屏看图右上角“位置”、长按“查看位置”，不连电脑也能看真实路径
- 可选底部“连接电脑”，支持局域网地址或 Tailscale 地址 + 密码
- 支持被微信/QQ 作为“默认相册/打开方式”打开图片和视频
- 内置更新公告

### 云端

- **123 云盘**：使用开放平台 `clientID` / `clientSecret`
- **WebDAV**：服务器地址、用户名、密码
- 云盘图片可浏览、查看、保存到本地
- 密钥只保存在电脑端，手机通过电脑代理读取，不把密钥下发到手机

### 连接方式

1. **局域网**：电脑和手机同一 Wi-Fi；电脑首页/设置里显示二维码和网址，手机扫码或输入网址；网址自带访问口令。
2. **Tailscale**：电脑和手机安装 Tailscale 并登录同一账号；电脑开启“允许 Tailscale 远程访问”并设置访问密码；手机输入 `http://100.x.x.x:端口/`（或 MagicDNS 名称）和密码。

> Tailscale 连接必须设置访问密码；仅开启开关不设置密码会被拒绝。不要把端口直接暴露到公网。

## 下载

请到 [Releases](https://github.com/darkdecade2/xphoto/releases) 下载。

- **v1.6.6**：`xphoto-portable.zip`（Windows 便携版 + Android APK）+ `xphoto.apk`
- **更早版本**：仅提供 APK，更新内容见对应 Release

### Windows

1. 解压 `xphoto-portable.zip` 到任意目录（不要在压缩包里直接运行）
2. 双击 `启动 xphoto.bat`
3. 首次启动如 Windows 防火墙弹窗，选择“允许访问”
4. 手机与电脑同一 Wi-Fi，点电脑左下角“手机连接”扫码

### Android

1. 安装 `xphoto.apk`
2. 首次打开允许“照片/视频”权限
3. 直接浏览手机本机相册；需要电脑相册时点右下角“连接电脑”
4. 连接电脑：输入电脑上显示的局域网网址，或 Tailscale 地址 + 访问密码

## 数据位置

- 电脑下载目录：`C:\Users\<你>\Pictures\xphoto下载`
  - `手机下载\<设备名>`：手机保存到电脑的图片
  - `电脑下载\<设备名>`：电脑端“存到电脑”的图片
  - `云盘\<云盘名>\...`：云盘保存到本地的图片
  - `.xphoto-trash`：电脑回收站
- 手机下载：`Download/xphoto`
- 手机回收站：`Pictures/xphoto/回收站`
- 电脑配置：`%APPDATA%\xphoto`

## 从源码运行

```bash
npm install
npm start          # Windows
npm run pack       # 打包 Windows 便携版
npm run build:apk  # 需要 JDK 17 + Android SDK，见 scripts/build-apk.ps1
```

需要 Node.js 20+。Android 构建需要 `ANDROID_HOME`、build-tools 35、platform 35。

## 安全说明

- 局域网访问使用随机口令 `?t=...`；关闭“局域网访问”后手机立即无法连接
- Tailscale 访问额外要求密码，密码使用 scrypt 哈希保存在电脑端
- 云盘密钥只保存在电脑端，不写入浏览器存储
- 不要把 18573 端口直接映射到公网；跨网络请用 Tailscale
